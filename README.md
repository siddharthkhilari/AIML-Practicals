# AIML Practicals

A collection of Artificial Intelligence and Machine Learning practicals implemented using Python. This repository contains practical implementations, datasets where applicable, visualizations, and output files to understand important machine learning algorithms and techniques.

## 📌 About the Project

The objective of this repository is to learn and implement fundamental Machine Learning concepts through practical programs. Each practical focuses on a specific algorithm or technique, with Python code and output visualizations wherever applicable.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Tools:** Visual Studio Code, Git, GitHub
- **File Formats:** Python (`.py`), Markdown (`.md`), PNG (`.png`)

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.9 or a compatible version
- pip package manager
- Visual Studio Code or another Python editor

### 1. Clone the Repository

```bash
git clone https://github.com/siddharthkhilari/AIML.git
```

### 2. Navigate to the Project Folder

```bash
cd AIML/AIML_Practicals-main
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ How to Run the Practicals

Navigate to the required practical folder and execute its Python file.

For example:

```bash
python practical_02_clustering/practical_02.py
```

Run each practical from the project root directory unless its README specifies a different working directory. Some practicals may require additional datasets, model files, configuration, or dependencies.
